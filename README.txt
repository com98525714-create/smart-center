Smart Center — نسخة تسجيل دخول فقط

المميزات:
- تسجيل دخول المالك عبر Supabase Auth بالبريد وكلمة المرور.
- استعادة كلمة المرور عبر البريد الإلكتروني.
- تسجيل خروج وحماية واجهة لوحة التحكم من الزوار غير المسجلين.
- بيانات أقسام السنتر تُحفظ محليًا في المتصفح (Local Storage) فقط.

مهم جدًا:
- هذه النسخة لا تستخدم جدول center_data ولا ترفع بيانات السنتر إلى قاعدة بيانات.
- Supabase مطلوب لخدمة Authentication فقط. لا تضع Secret key أو service_role key في ملفات الموقع.
- المفتاح المستخدم في الواجهة يجب أن يكون Publishable key فقط.
- لأن البيانات محلية، لن تتزامن تلقائيًا بين الأجهزة أو المتصفحات. استخدم النسخ الاحتياطي من داخل المنصة لنقل البيانات.

النشر على GitHub Pages:
1. ارفع index.html وstyle.css وapp.js وassets-logo.png إلى جذر المستودع.
2. تأكد من تفعيل GitHub Pages من Settings > Pages.
3. في Supabase Authentication > URL Configuration أضف رابط موقع GitHub Pages إلى Site URL وRedirect URLs.
4. أنشئ حساب المالك من Authentication > Users (أو أرسل دعوة/إعادة تعيين كلمة المرور). أوقف التسجيل العام بعد إنشاء الحساب.

لا تحذف مشروع Supabase؛ تسجيل الدخول يعتمد على Authentication فيه. ويمكن ترك جدول center_data القديم دون استخدام.


النسخ الاحتياطي والاستعادة:
- من إعدادات السنتر اختر "تنزيل نسخة احتياطية JSON" لتنزيل ملف يحتوي على بيانات الأقسام والإعدادات.
- احتفظ بالملف في مكان آمن، ويفضل نسخة إضافية على وسيط تخزين موثوق.
- لاستعادة البيانات اختر "استيراد نسخة" وحدد ملف JSON سابقًا.
- قبل الاستعادة، ينزّل النظام تلقائيًا نسخة أمان من البيانات الحالية.
- الاستعادة تستبدل بيانات المتصفح الحالية بالبيانات الموجودة في الملف.
- ملفات النسخ الاحتياطية قد تحتوي على بيانات طلاب وأولياء أمور ومعلومات مالية؛ لا تشاركها علنًا.
